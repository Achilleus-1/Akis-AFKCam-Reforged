# Contributing

Use a focused branch and pull request. Explain the problem, the resulting behavior,
and how you checked it. Keep unrelated formatting out of the change.

Run `python tools/check_repository.py` with Python 3.12 before submitting. See
[DEVELOPMENT.md](DEVELOPMENT.md) for project-specific builds and dependencies.
GitHub Actions repeats the supported checks on pushes and pull requests.

Preserve upstream attribution, license notices, third-party exceptions, and the
distinction between original mod contributions and port modifications. See LEGAL.md.
Do not commit personal records, credentials, local IDE files, notebook outputs,
or generated builds. Report security issues through [SECURITY.md](SECURITY.md).
